# C Algorithmic Labs

Collection of C programming labs and algorithmic problem-solving sessions, implemented using the Code::Blocks IDE.

## Getting Started: Running C in Code::Blocks

Follow these simple steps to set up, compile, and run your C programs from scratch:

### 1. Create a New Project
1. Open **Code::Blocks**.
2. Go to **File > New > Project...**
3. Select **Console application** and click **Go**.
4. Choose **C** as your programming language and click **Next**.
5. Enter your **Project title** and choose the folder where you want to save your repository workspace. Click **Next**.
6. Ensure your compiler is set to **GNU GCC Compiler**, then click **Finish**.

### 2. Write Your Code
1. In the left-hand **Management** panel, expand your project folder and click on the **Sources** directory.
2. Double-click on **`main.c`** to open the default template.
3. Replace the template with your C code (e.g., your sum calculation or conditional logic).

### 3. Build and Run
* **Compile only:** Click the **Gear icon** (Build) in the toolbar, or press `Ctrl + Shift + B`.
* **Run only:** Click the **Play icon** (Run) in the toolbar, or press `Ctrl + F10`.
* **Build & Run (Recommended):** Click the **Gear with Play icon** (Build and run) in the toolbar, or press **`F9`**. A console window will pop up showing your program's output.
